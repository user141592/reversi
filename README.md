# reversi

ターミナル上で2人対戦できるリバーシ(オセロ)です。

## 必要なもの

- Python 3.6 以上
- NumPy

```bash
pip install numpy
```

## 遊び方

```bash
python reversi.py
```

- ● が先手(黒)、○ が後手(白)です。
- 自分のターンになったら、コマを置きたい位置の「行」と「列」をそれぞれ 1〜8 の数字で入力します。
- 相手のコマを挟めない位置には置けません。
- 置ける場所がないプレイヤーのターンは自動的にスキップされます。
- 両者とも置ける場所がなくなるとゲーム終了となり、コマの多い方の勝ちです。
